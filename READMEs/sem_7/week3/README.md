## Тема практического занятия: Хостинг продающего сайта (лендинг)

### Что сделано

Одностраничный продающий сайт (лендинг) PiConstruct — **статическая страница без зависимостей и сборки**: `index.html` + `styles.css` + `script.js`. Лежит в [`attachments/landing/`](attachments/landing/index.html), открывается любым статик-хостингом (GitHub Pages, Vercel, Netlify) или просто открытием `index.html` в браузере.

Оформление — по дизайн-системе PiConstruct (неделя 1): единственный шрифт Rubik, цвета логотипа (Ink, зелёный `#2BDD93`, циан `#2CABDD`), брендовый градиент, карточки 16px, пилюли-бейджи. Поддерживаются тёмная и светлая темы: по умолчанию тема следует системной настройке пользователя (`prefers-color-scheme`), кнопкой в шапке тему можно переключить вручную (выбор сохраняется).

Скриншот в hero — реальный интерфейс конструктора с готовой сценой «Глобус шаурма».

### Структура лендинга (9 блоков)

| № | Блок | Содержание |

Целевое действие — заявка: форма собирает письмо через `mailto:`, поэтому работает на любом статик-хостинге без бэкенда.
